# Process

I used ChatGPT throughout the writing process for brainstorming, structuring the essay, translating some of my original ideas from Chinese into English, and revising the language and organisation of the final text. I used VS Code to write and edit the Markdown files, and Git and GitHub to track different stages of the essay and run the assignment check.

One AI suggestion I kept was the idea of focusing on the difference between working code and a successful interaction. This helped me connect the question to my graduation project. Even if AI can generate code that makes a clap trigger sound and visual feedback, I still need to judge the timing, sensitivity, and relationship between different forms of feedback based on the experience I want to create.

One suggestion I rejected was the general argument that human creativity cannot be replaced by AI. I felt this was too broad and did not represent my position. I am comfortable using AI as part of my design process. What matters to me is having enough understanding of programming to question, modify, and make my own decisions about what AI produces.
